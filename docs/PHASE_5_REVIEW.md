# Phase 5 — Launch Engine

Завершено 2026-11-10. Minecraft 1.21.1 запускается кнопкой «Играть» для активного профиля. В development можно использовать тестовый вход, в production перед запуском нужна действующая сессия Ely.by. Игра запускается в своём процессе, Launcher показывает его состояние и код выхода.

| Модуль | Результат |
|---|---|
| `crates/launcher-core/src/launcher/` | Подстановка аргументов по метаданным 1.21.1, classpath, настройка памяти и Java, запуск без shell, безопасный сбор stdout/stderr |
| `crates/launcher-core/src/installer/`, `storage/`, `runtime/` | Повторная проверка ресурсов, свежая папка для нативных библиотек, блокировки профиля и запись для восстановления после сбоя |
| `src-tauri/src/commands/game.rs` | Main-only IPC для запуска, отмены, остановки и подключения к состоянию процесса |
| `frontend/src/features/game/` | Кнопка «Играть», отображение событий, ошибки, остановка и защита от запоздавших ответов |

Подробности аргументов, журналов и восстановления описаны в [Launch Process](LAUNCH_PROCESS.md).

## Проверка

- Метаданные 1.21.1 проверены для Windows x64, Linux x64, macOS x64 и macOS ARM64. Тесты проверяют classpath, UUID, значения аргументов, правила платформы, пустые параметры и неизвестные placeholders.
- Тесты Rust проверяют реальный дочерний процесс, код ошибки, остановку, фильтрацию токенов, запись запуска и освобождение блокировки. IPC-тесты проверяют запрет команды без сессии, запрет подстановки токена из frontend и ACL. UI-тест проверяет команду для выбранного профиля, обработку событий и поздний ответ.
- На macOS ARM64 debug с Development / Mock запустил официальный клиент 1.21.1 на управляемой Java. Журнал подтвердил запуск render thread, OpenAL и создание атласа GUI. Первый прогон завершился по тестовому таймеру. В отдельной тестовой сборке кнопка «Играть» запустила Java как дочерний процесс Launcher. После сигнала TERM тестовый Launcher записал код выхода 143 и вывод обоих потоков. Временная папка запуска была очищена. Инструмент управления окном ответил тайм-аутом на повторное считывание интерфейса. Последний статус UI проверяется отдельно тестом событий.
- В финальном прогоне core супервизор остановил игру, записал журнал и удалил запись запуска. В отдельном прогоне с синтетической сессией JVM загрузила закреплённый Authlib Injector 1.2.8 и метаданные endpoint Ely.by. Minecraft инициализировал графику и звук. [Локальные результаты и SHA256 DMG](validation/phase-5-local.json).
- Локально прошли 43 frontend-теста, 53 теста ядра в обычной сборке и 55 с `dev-auth`, по 13 desktop IPC-тестов в debug и release. Rustfmt, Clippy и обе защиты от release + dev-auth прошли.
- Финальный [CI run 42701859712](https://github.com/HerrChichikov/minecraft-rust-launcher/actions/runs/42701859712) проверил commit `33b5362f811dbc0556e4dd866339129cf1be93af`. Успешны frontend и Windows x64, Linux x64, macOS Intel и ARM64. Собраны четыре пакета и четыре отчёта о проверках. На Windows понадобился повтор одного job после нестабильного теста на число запросов к локальному HTTP-серверу. Тот же commit прошёл повтор. Ранний Linux run остановился на тесте повторного открытия хранилища. Явное освобождение файловой блокировки при наличии дубликата дескриптора покрыто новым тестом, итоговый Linux run прошёл. [CI receipt](validation/phase-5-ci.json).
- Графические прогоны Windows, Linux и Intel Mac относятся к Phase 7.

## Ограничения

Графический smoke выполнен с тестовой сессией. Запуск агента проверен с синтетической сессией. Подключение к игровому серверу с реальным аккаунтом Ely.by и выход через меню игры ещё предстоит проверить. При каждом запуске установщик повторно запрашивает официальные метаданные и проверяет хеши файлов. При аварии Launcher используется консервативное ручное восстановление. Во время игры поддерживается один процесс Java на приложение.
