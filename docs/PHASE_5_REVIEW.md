# Phase 5 — Launch Engine

Обновлено 2026-11-10. Minecraft 1.21.1 запускается кнопкой «Играть» для активного профиля. В development можно использовать тестовый вход, в production перед запуском нужна действующая сессия Ely.by. Игра запускается в своём процессе, Launcher показывает его состояние и код выхода.

| Модуль | Результат |
|---|---|
| `crates/launcher-core/src/launcher/` | Подстановка аргументов по метаданным 1.21.1, classpath, настройка памяти и Java, запуск без shell, безопасный сбор stdout/stderr |
| `crates/launcher-core/src/installer/`, `storage/`, `runtime/` | Повторная проверка ресурсов, свежая папка для нативных библиотек, блокировки профиля и запись для восстановления после сбоя |
| `src-tauri/src/commands/game.rs` | Main-only IPC для запуска, отмены, остановки и подключения к состоянию процесса |
| `frontend/src/features/game/` | Кнопка «Играть», отображение событий, ошибки, остановка и защита от запоздавших ответов |

Подробности аргументов, журналов и восстановления описаны в [Launch Process](LAUNCH_PROCESS.md).

## Проверка

- Метаданные 1.21.1 проверены для Windows x64, Linux x64, macOS x64 и macOS ARM64. Тесты проверяют classpath, UUID, значения аргументов, правила платформы, пустые параметры и неизвестные placeholders.
- Тесты Rust проверяют реальный дочерний процесс, код ошибки, остановку, фильтрацию токенов, запись запуска и освобождение блокировки. IPC-тесты проверяют запрет команды без сессии, запрет подстановки токена из frontend и ACL. UI-тест проверяет команду для выбранного профиля, обработку событий и поздний ответ.
- На macOS ARM64 debug с Development / Mock запустил официальный клиент 1.21.1 на управляемой Java. Журнал подтвердил запуск render thread, OpenAL и создание атласа GUI. Первый прогон завершился по тестовому таймеру. В отдельной тестовой сборке кнопка «Играть» запустила Java как дочерний процесс Launcher. После сигнала TERM тестовый Launcher записал код выхода 143 и вывод обоих потоков. Временная папка запуска была очищена. Инструмент управления окном ответил тайм-аутом на повторное считывание интерфейса. Последний статус UI проверяется отдельно тестом событий.
- Статус проверок на остальных платформах публикуется по результату GitHub Actions. Графические прогоны Windows, Linux и Intel Mac относятся к Phase 7.

## Ограничения

Графический smoke выполнен с тестовой сессией. Проверка подключения к игровому серверу с Ely.by и работа агента в реальном игровом сеансе остаются открытыми. При каждом запуске установщик повторно запрашивает официальные метаданные и проверяет хеши файлов. При аварии Launcher используется консервативное ручное восстановление. Во время игры поддерживается один процесс Java на приложение.
