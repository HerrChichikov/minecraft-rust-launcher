# Phase 6 — UI/UX

Launcher получил три экрана «Игра», «Аккаунт» и «Настройки». На главном экране видны версия Minecraft, активный профиль, статус файлов и карточка аккаунта с аватаром из инициалов. Гость переходит к входу из основного действия. После входа доступна кнопка «Играть».

| Область | Изменение |
|---|---|
| Интерфейс | Адаптивная навигация, оформление на SCSS и собственная SVG-иллюстрация. При переходе фокус попадает на заголовок экрана. |
| Аккаунт | Ely.by, TOTP, восстановление сессии и явный переключатель тестового входа в Development. Черновик пароля и кода очищается при уходе с экрана. |
| Настройки | Создание и выбор профиля, минимум и максимум RAM, управляемая или своя Java, параметры JVM и папка данных. Черновики настроек сохраняются при переходах между экранами. |
| Установка и запуск | Общая подписка на события и снимки состояния IPC. Видны проверка, загрузка, восстановление, подготовка Java, запуск и завершение процесса. Можно отменить подготовку или подтвердить принудительную остановку. |

Процент относится к файлам с известным объёмом. Показатель скорости использует переданные байты, а подготовка Java отображается без процента. Запись о прошлой установке обозначается как «Файлы ранее подготовлены». Лаунчер проверяет их перед запуском.

Автоматические проверки включают переходы между экранами, сохранение состояния установки, очистку черновика пароля, подготовку перед Play, поздние ответы, отмену, подтверждение остановки и проверку настроек. Тест передачи по локальному HTTP проверяет, что скачивание, проверенное повторное использование и восстановление повреждённого файла дают соответствующие состояния.

На macOS Apple Silicon проверены три экрана в отдельной Tauri-сборке, загрузка со скоростью и отменой, тестовый вход, сохранение RAM и распознавание уже подготовленных файлов. Кнопка «Играть» запустила Minecraft 1.21.1 с тестовой сессией. Launcher отобразил ход проверки, подготовку Java, работающую игру, подтверждение принудительной остановки и состояние после неё. Журнал подтвердил графику и звук, а запись активного запуска была удалена. Использовалось отдельное тестовое хранилище.

Локально прошли 44 frontend-теста, 53 теста ядра по умолчанию, 55 с `dev-auth` и по 13 IPC-тестов для debug и release. Проверено, что обе Rust-сборки отклоняют `dev-auth` в release. Для Apple Silicon собран DMG, проверена ad-hoc подпись приложения. [Протокол и SHA-256 пакета](validation/phase-6-local.json).

В GitHub Actions прошли frontend и четыре нативные задачи на Windows x64, Linux x64, macOS Intel и macOS Apple Silicon. На каждой платформе проверены установка Minecraft и Java, повторное использование файлов, целостность Authlib Injector и сборка пакета. Все восемь артефактов опубликованы. Кроссплатформенные графические прогоны и подключение к серверу с реальным аккаунтом Ely.by остаются задачами Phase 7.
